# Plott & Sunder (1982) — LLM 智能体复现

[English](README.md) · **中文**

用 LLM 智能体复现 Plott & Sunder,*"Efficiency of Experimental Security Markets with
Insider Information"*,JPE 90(4) 的全部**五个市场**。

每个市场里,9 或 12 个智能体在 11–14 个"市场年"中交易单期证书。每年开始时摇奖笼决定
本年支付哪种红利,部分人拿到线索卡。核心问题是:**价格和持仓会落在理性预期(RE)均衡上,
还是先验信息(PI)均衡上**——也就是不知情的人能不能从价格里读出状态。

两部分:

- **Python**(`ps1982/`)跑市场和模型调用,每次运行写一份只追加的 JSONL 事件流
- **Node.js**(`web/`)读这些日志,提供中/英双语的回放查看器和指标面板

支持三个模型端点:DeepSeek 官方 API、阿里云百炼(同权重、约半价)、Google Vertex AI
的 Gemini。切换厂商只需改 scenario 里的一行。

### 为什么是三个控制市场而不是一个

价格发现记作 `D = (成交价 − v̄) / (re − v̄)`,即价格实际走完了「从无知情者水平到理性预期
价格」这段距离的多少。有三件互相独立的事情会让这个数在买方和卖方侧含义不同,而论文的
市场族三件都占。

1. **距离不等。**市场 4 要求买方推 +165 francs、卖方只要 −35,同样一 franc 的移动在卖方
   侧记分高五倍。**市场 6** 把它拉平到两侧各 80。
2. **靶子是区间而不是点。**24 张证书、最高类型 4 个人,只要价格落在「次高知情估值」与
   「最高知情估值」之间,竞争性配置就成立——所以一个**仅仅是竞争性**的价格本身就占据
   一段 D。市场 6 的这段在买方侧宽 0.875、卖方侧只有 0.125,是全族最失衡的。
   **市场 7 和 8** 把它拉平:各 0.300 与各 0.200。
3. **知情者未必同向。**「买方状态」只意味着 `re > v̄`,而 re 是**最高**类型的估值。
   市场 3、4 的买方状态里,六个内幕者有两个想**卖**;市场 5 三个状态全是净卖压。
   市场 6、7、8 里六个内幕者在每个状态下想的都一样。

市场 7 和 8 只差一件事:**谁在什么时候持有**。家族里其他所有市场中,定 v̄ 的那个类型同时
也是买方状态的持有者,所以买方信号来了不需要换手、卖方信号才需要——这是前两条修不到的
不对称。市场 8 让每个类型各司一职,两个状态因此要求同样的重新配置。

### 搭便车恒等式

造这几个控制市场时,顺带查出一件对论文的市场同样成立的事。

**买方侧永远不可能有未知情者帮忙。**v̄ 的定义是 `max_t E[红利_t]`,即任何未知情者能持有的
最高估值,而买方状态的定义就是 `re > v̄`。所以没有任何未知情者会把证书估到买方 RE 价之上
——任何市场、任何参数下都是如此。买方侧的每一分价格发现,都必须来自真的学到了东西的人。

**卖方侧没有这个恒等式,而论文每个市场都有帮手**:总有某个类型的先验期望掉在卖方 RE 价
**以下**,那些未知情者什么都没推断出来就会在 RE 价上卖。

| | 市场 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 未学到任何东西就能推动**卖方**价格到位的未知情者 | 2/6 | 2/6 | 2/6 | **4/6** | 0 | 0 | 0 |
| **买方**侧同一项 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

所以「知情卖方泄密、知情买方藏信息」里有一部分是参数的会计性质。它是可测的:跑**脚本化**
RE 基线——已经知道状态的算法——市场 3 会给出 **+0.297** 的买卖差,期间没有任何策略参与,
而市场 7 和 8 是 −0.337 与 −0.509。市场 6、7、8 是唯三两个方向都需要真实推断的市场,
这也正是它们脚本化卖方侧接近 0 的原因:没有搭便车者,价格就永远到不了「基于价格水平的
推断规则」需要的那个位置,于是没人学得会。

脚本化规则**没有为它们改动**——它是已完成的那些 session 的固定参照点。这几个市场上的
LLM 实验,读法是「相对这个实测基线的差」,而不是对 1.0。

**理论预测是推导的,不是抄的。**`Market.theory_price()` 从红利和先验算出 RE/PI,
结果在论文印出的市场 2/3/4/5 的每一格上都吻合。市场 1 论文明说省略了
("information given to insiders was probabilistic. Predictions are not given here"),
所以它的预测由我们推导,而其余四个市场的完全吻合就是相信它的依据。

### 两条臂

- **`paper`** —— 用 Table 1 记录的那条实现序列。种子只改变轮转顺序、抽签和席位→姓名映射,
  所以这条臂是**同一条序列的重复**
- **`random`** —— 按该市场**自己的先验**重抽每期状态,信息设计保持不变。种子推导出序列本身,
  所以这条臂检验的是**结论能否超出那一次实现**

市场 1 的线索样本会跟着状态一起重抽——样本是**依条件于实现状态**从对应的箱子里抽的,
状态变了却留着原样本,描述的是一个不可能发生的世界。

## 引擎正确性闸门

花钱调模型之前,先跑一场**脚本化**智能体的市场。每种应该产出它自己那个模型的结果;
如果没有,问题在引擎而不在智能体。

```bash
make gate                    # 市场 3,基准情形
make gate6                   # 等距控制市场
make gate7 && make gate8     # 两个等宽控制市场,跑在它们的实验臂实际用的种子上
```

| 智能体 | Y 内幕期 | X 内幕期 | E%(内幕期) | 读法 |
|---|---|---|---|---|
| `re` | 收在 **175** = RE | 收在 **354–400** = RE | 95–100 | 价格与持仓到达 RE 均衡 |
| `pi` | 停在 **220** = PI | 367–400 | **65–69** | 从不从价格学习,证书落在错误的手里 |
| `zi` | 400 附近噪声 | 400 附近噪声 | 60–90 | 约 48% 的价格变动朝向 RE,即随机 |

重点不是 `re` 会收敛,而是 `pi` **不会**。引擎能同时表达两个模型,所以一次真实运行落在
其中一个上,才说明了智能体的某种性质。

几个闸门刻意分开而不合并,这样 `make gate` 变红时,含义始终是**复现**坏了。控制市场
另有闸门,因为它们的基线行为本就不同——而那个不同是结果,不是故障:

| 市场 | 脚本化 `re` 买方侧 | 卖方侧 | 该臂自身的零假设差 |
|---|---:|---:|---:|
| 3 | 0.733(n=9) | 1.030(n=15) | **+0.297** |
| 6 | 0.839(n=13) | 0.633(n=11) | −0.206 |
| 7 | 0.886(n=18) | 0.549(n=9) | −0.337 |
| 8 | 0.923(n=15) | 0.414(n=12) | −0.509 |

种子 42/43/44 合并。市场 6–8 的卖方侧是**双峰**而不只是低——市场 7 的九个卖方期是四个
接近 1.0、五个接近 0.1——因为没有搭便车者(见上),价格永远到不了基于价格水平的推断规则
需要的位置。LLM 智能体有脚本化智能体没有的通道:它能看见六个不同座位在抛售而没人接。
这够不够,正是控制臂要测的。

> **两处已知限制**:脚本化 `re` 读不懂市场 1 的十位线索串(它检查 `card in states`,
> 样本永远不满足),会退回价格推断,所以在市场 1 上不是有效参照;而它的推断只看价格
> **水平**,这正是上表在量的东西。LLM 智能体不受第一条影响(机制写在提示词里)。
> 两条都不修——这条规则是每一场已完成实验的固定参照点。

### 可分离期这个筛选条件看不见什么

在内部人期里,先验信息价是全场最高估值 `PI = max(知情者, 不知情者)`,
而理性预期价就是知情者那个估值。于是

```
RE ≠ PI   ⟺   RE < 不知情者水平   ⟺   知情者想要「卖」
```

这是恒等式而非倾向:26 场实验里,可分离期与卖方侧期是同一批 89 个期,无一例外。
**所以论文的招牌结论和上面那张表,讲的都只是卖方侧。**知情者做买方的那些期,
按构造就在筛选条件之外——不是被忽略,是够不着。

`metrics.price_discovery_by_informed_side()` 照样给它们打分:

```
discovery = (价格 − 不知情者水平) / (RE − 不知情者水平)
```

| | LLM 智能体,26 场 | 人类,市场 3 | 人类,市场 5 |
|---|---:|---:|---:|
| 知情者=**卖方** | **+1.13**(89 期) | +1.08 | +1.09 |
| 知情者=**买方** | **+0.04**(99 期) | +0.80 | +0.66 |

人类那两列是论文图 4、图 6 打印的均价,用同一个公式算出来的。
**这个非对称性在论文自己的数据里就有**——本项目是把它测了出来,不是发现了人类没有的现象。
26 场里 23 场同向,配对差中位数 +1.05。

真正不同的不是有没有,而是会不会消失:

```
按该状态第几次出现          第1次    第2次    第3次    第4次    第5次
  卖方侧,LLM               +1.17   +1.30   +1.10   +1.02   +1.03
  买方侧,LLM               −0.01   +0.13   +0.04   +0.10   −0.51
  买方侧,人类(市场3,X态)    +0.63   +0.80   +0.98
  买方侧,人类(市场5,Z态)    −0.06   +0.60   +0.78
```

而在一期之内,卖方侧从不需要收敛:

```
                     首笔成交    均价    收盘
  知情者在卖出         +1.14    +1.13   +1.11
  知情者在买入         −0.11    +0.04   +0.04
```

**卖出这个动作本身就泄露了信息**——想卖的知情者必须压价,所以该期第一笔成交
就已经带着状态,人类和 LLM 都一样。买入不会:把价格抬到 RE 只会毁掉买方自己的剩余。
人类被试仍然学会了把它计入价格,到某个状态第三次出现时就到了 RE,
这正是论文所说的内幕优势随重复"完全消失";这些智能体重复五次也没有。

市场 1 的第 11 期把机制直接摆了出来:那一期人人持有同一张线索卡,
证书对 I 型的价值是 349.3。三个 I 型智能体自报的保留价是 349、349、348——
数字他们有——然后在 **300–302** 成交,那正是 II 型的估值,压过次高类型就收手。
同一期的人类被试成交在 347。证书最终仍落到 I 型手里(18 张中的 17 或 18 张,与 RE 预测一致):
**配置假说成立而价格假说失败,因为剩余全被买方拿走了。**

**仍未解决的。**人类那两列各自只有一次实现的序列——论文自己的收敛检验是表 6 的利润比,
不是这些轨迹。而这些实验每期跑三轮,对面是连续口头拍卖,所以买方侧竞价不足有可能是
回合数截断的产物;上面"首笔成交"那一行是反证——一个从第一笔到最后一笔都不动的价格,
不像是时间不够用的价格。直接的检验是在市场 4 上跑一条五轮臂,与这里报告的五场同种子配对。

## 三条硬约束

写提示词时不可违反,`tests/test_prompts.py` 对全部 (市场, 席位) 组合逐一守卫:

1. **"probability" 这个词永不出现。**论文明确记载被试是用摇奖笼作为**机械装置**训练的,
   概率语言被排除在说明书之外。这条约束逼出了两件事:每个市场的先验必须能用**整数个球**
   表达(所以有 `Market.bingo_total`),市场 1 的不完美线索必须写成**两盒筹码**
   而不是似然函数。
2. **不透露**有几种投资者类型、别人的红利是多少、知情者是否固定、哪种状态更可能。
3. **共同知识按市场给。**论文说"除市场 1 外,各市场的参与者都能推断出红利逐期不变"——
   所以市场 1 **不给**这条。

理论值(`THEORY_*`)只用于事后分析和查看器,**永不进入提示词**。

## 一次运行的日志里有什么

一个 JSONL 文件,一行一个事件,`agent_visible` 标记它是否进入了智能体能看到的记录。
智能体可见的市场日志是**过滤出来的**,不是另存一份。

| 事件 | 内容 |
|---|---|
| `session_start` | 配置、种子、市场号、实现序列、线索卡、内幕者名单、**该市场的 RE/PI 理论表**(全部对智能体隐藏) |
| `brief` | 推送给智能体的简报原文,逐字节 |
| `model_turn` | 完整 prompt、完整 completion、思维链、token 用量、重试、延迟 |
| `action` / `broadcast` / `trade` / `violation` | 决策、表态、成交、被市场拒绝的尝试 |
| `reflection` | 期末笔记与成交笔记 |
| `period_end` / `session_end` | 结算与汇总 |

理论表写进日志,是为了让查看器和任何下游读者**从运行本身取值**,而不是各自维护一份——
查看器原来那份是市场 3 的硬编码,对其它市场会静默出错。

## 批次运行

```bash
./.venv/bin/python batch_plan.py --show    # 看计划,不执行
./run_batch.sh                             # 全部起
./run_batch.sh m3_paper_0 m3_gem_paper     # 只起指定的
./.venv/bin/python watch_batch.py --loop 60
./resume_batch.sh                          # 断点续跑
```

主计划是 **26 场**:五个市场各 5 场 DeepSeek(2 论文序列 + 3 随机重抽)+ 市场 3 的 1 场
Gemini。按实测约 $50、5–6 小时。

另有两条后续臂刻意留在计划之外——那 26 场是对一个已发表实验的复现,而这两条改动的是那个
实验本来没有的东西:

```bash
./.venv/bin/python batch_plan.py --rounds-arm    # 市场 4,每期 4/5/6 回合
./run_rounds_arm.sh                              # 6 场

./.venv/bin/python batch_plan.py --control-arm   # 市场 7 和 8,种子 42/43/44
./run_control_arm.sh                             # 6 场,约 $15、8–10 小时
MARKETS=-m7 ./run_control_arm.sh                 # 只跑一个市场的三场
```

控制臂的种子**不做筛选**,由此产生的不平衡是记录下来而不是修掉的:等距要求
`p(买方状态) > 1/2`,所以九个内幕期在期望上就偏买方,**可分离的那一侧**因而被结构性地
少抽——市场 7 抽到 18 买 / 9 卖,市场 8 抽到 15 / 12。「按事先声明的标准筛种子」和
「直接设计序列」两条路都考虑过并放弃了:筛过的种子就是挑出来的种子。所有后果都钉在
`tests/test_markets.py` 里,而不是只写在正文中。

**并发是结构性约束,不是统计的。**一个 session 单线程推进各阶段,所以任何时刻最多
`broadcast_workers` 个请求在飞——`场次 × W` 是数学上限。百炼端点容量 50–80,
Vertex 用动态共享配额(没有可调的上限,只能少要)。scenario 里的注释记录了实测依据。
